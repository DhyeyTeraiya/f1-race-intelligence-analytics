## How recognition works

- GitHub automatically records public authorship in the repository's **Contributors** graph.
- Accepted pull requests and issue discussions remain linked to each contributor's GitHub profile.
- This page provides an additional, human-readable showcase for contributors who opt in.
- If you would like your entry updated or removed, open an issue or pull request.
