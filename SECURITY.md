# Security Policy

## Supported versions

The `main` branch is the supported version of this project.

## Reporting a vulnerability

Please do **not** open a public issue for a security vulnerability. Email [dhyeyteraiya@gmail.com](mailto:dhyeyteraiya@gmail.com) with:

- A clear description of the issue
- Reproduction steps or a proof of concept
- The affected file, component, or dependency
- Any suggested mitigation

Do not include API keys, credentials, private data, or other secrets in the report.

The maintainer will acknowledge the report, investigate it, and coordinate a fix or public disclosure when appropriate. This project does not promise a specific response time, but responsible reports are appreciated.
